# Main figures

Run `python figures/plot.py` from the repository root to regenerate the three PNGs and matching SVGs. The only data input is [seven_peer_curves.csv](../results/seven_peer_curves.csv).

- [Setting 1](setting-1-cheating.png): DeepSeek private-scorer access, regardless of subsequent use of the key.
- [Setting 2](setting-2-cooperation.png): DeepSeek accepted risky-probe calls, regardless of whether the task was destroyed.
- [Setting 3](setting-3-deployment.png): transfer to Nova, among decided episodes, for base Qwen and KREL.

All use series C only. The horizontal axis replaces opposing reports with action reports in a log of fixed length seven. Each report was written by an earlier model, but this log mixture was assigned, not generated by seven live peers in the plotted episode. Each evaluated agent still has a multi-step tool rollout and writes its own note afterward.

Vertical bars are pointwise 95% Wilson intervals. Dashed lines are separate empty-log reference point estimates, not another seven-peer condition. Lines connect observations, not a fitted response law. Small horizontal offsets distinguish the two deployment models. These intervals describe sampling uncertainty within this setup, not uncertainty about different prompts, report pools, models, or endpoints.
